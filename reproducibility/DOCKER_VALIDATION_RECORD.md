# Clean-environment validation record (slim Docker image)

Date: 2026-11-26. This records one run of `reproducibility/Dockerfile.repro` and
`reproducibility/docker_validate.sh`. The image was built locally and has not been published.

## Build

```
docker build --network host --build-arg HTTPS_PROXY --build-arg EXTRA_CA_B64=... \
    -f reproducibility/Dockerfile.repro -t axisforge-repro .
```

- **Base image:** `ubuntu:24.04`, pulled from the public mirror `mirror.gcr.io/library/ubuntu` (Docker Hub
  was rate limited). Repo digest `sha256:562111b88caa79c71391c0c4d3c2114a7d5c35915c20561fd893cb1e07929e6b`.
- **Result image:** `sha256:c97aaf2bc979…`, 1.61 GB.
- **Toolchain:**
  - Python 3.12 with the statistics packages pinned in `reproducibility/requirements-lock.txt` (numpy, scipy,
    scikit-learn, pytest and their dependencies);
  - rustup with the repository's pinned toolchain;
  - `cargo build --release --locked -p axisforge-cli`.
- **Build arguments.** `EXTRA_CA_B64` adds the build machine's HTTPS-proxy CA certificate, a public
  certificate. It is only needed behind that proxy, and the image is not distributed. Without the argument,
  the image builds against the system CAs.
- **Timings:** apt 36 s, Python packages 17 s, cargo build 126 s.
