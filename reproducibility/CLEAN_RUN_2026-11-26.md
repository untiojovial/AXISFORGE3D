## Scope

This is a **partial** reproduction. It recomputes the statistics from the committed per-object data; it does
not re-run planning or physics. A **full** reproduction needs the datasets (fetched as described in
`tools/fetch/README.md`), the release build, and the per-phase pipelines listed in `REPRODUCIBILITY.md`. It
was not run from a clean machine here. The native equivalence check (`native_inference_validation.json`)
re-ran the planner on all 661 development and EGAD objects in the working environment.
