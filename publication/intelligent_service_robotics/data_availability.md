# Data availability

The shortened statement is in `main.tex` (Statements and Declarations). This file is the full version. Nothing here
claims that all data are publicly available: the exclusions are listed.

## Public datasets used

| Dataset | Original source | Licence | Role | How it is obtained |
|---|---|---|---|---|
| EGAD (Morrison, Corke and Leitner, RA-L 2020) | the dataset's official archives | BSD-3-Clause (`research/phase7/EGAD_LICENSE.txt`) | Both confirmations (positions 0–299 and 300–499 of the frozen draw) | fetch scripts; SHA-256 of every mesh in `research/phase7/egad_selection.json` |
| Google Scanned Objects (Downs et al., ICRA 2022) | the dataset's public distribution | CC BY 4.0 | Development (100 library parts and 200 test parts) | fetch scripts at a pinned version |
| YCB Object and Model Set (16 objects) | YCB benchmarks (S3 index and AWS Open Data registry) | CC BY 4.0 for the data | Development library | meshes from `pybullet-object-models` at commit `57cc400`, regenerated by `tools/verify/ycb_pick.sh` |

The meshes are not redistributed.

## Derived data

The repository also holds data derived from the meshes:

- part lists;
- the frozen EGAD draws, with per-mesh hashes;
- candidate features and labels summaries;
- the dynamic-validation outcomes per object.

GSO-derived data carry the CC BY 4.0 attribution, and EGAD-derived data the BSD-3-Clause notice.

## Excluded for licence reasons

These classes are left out of the reproducibility package `axisforge3d-research-reproducibility`, which is built
locally and not published.

| Class | Reason | Where it is | How to regenerate |
|---|---|---|---|
| Descriptors computed with DINOv3 | DINOv3 License (redistribution only under that licence) | in the repository history, under the DINOv3 License; not in the package | the embedding scripts, with the author's gated DINOv3 access |
| Per-object YCB descriptors and geometry | conservative decision on YCB redistribution | in the repository; not in the package | `tools/verify/ycb_pick.sh` and the feature scripts |

Each excluded file is listed in the package's `MANIFEST_EXCLUDED.json` with its reason and regeneration route.
Excluding a file from the package does not remove it from the Git history.

## Large data kept local

- The exhaustive candidate catalogues.
- The per-trial simulation logs of development.

`research/phase7_extension/REPRODUCIBILITY.md`.
