## Template

The Springer Nature LaTeX template is not redistributed here because its licence terms were not
reviewed.

- Download page: Springer Nature's "LaTeX author support" page.
- Zip used: content id 18782940, version 12.
- SHA-256 of the zip: `812e76dcaa9c28dc1bff1fb6065d51729b67d4ea140552a05088317414a3ecae`.
- Files needed: `sn-jnl.cls` and `bst/sn-mathphys-num.bst`. Copy them next to `main.tex`.
- ORCID. The class's `\orcid` macro links a logo file (`Orcidlogo.eps`) that is not among the files used here, so `main.tex` redefines `\orcidlogo` to print the iD as linked text. Remove the redefinition if the logo file is supplied. Margins and fonts are unchanged.

## Build

```bash
python tools/research/phase7/make_tables.py --results research/phase7/results --out publication/intelligent_service_robotics/tables
python tools/research/phase7_extension/make_tables_x.py --out publication/intelligent_service_robotics/tables
python tools/research/phase7/make_figures.py --results research/phase7/results --out publication/intelligent_service_robotics/figures
python tools/research/phase7_extension/make_figures_x.py --out publication/intelligent_service_robotics/figures
(cd publication/intelligent_service_robotics/figures && pdflatex fig_overview && pdflatex fig_effects)
cd publication/intelligent_service_robotics
pdflatex -no-shell-escape main && bibtex main && pdflatex -no-shell-escape main && pdflatex -no-shell-escape main
# the same for supplementary, main_anonymous and supplementary_anonymous
pdflatex -no-shell-escape title_page && pdflatex -no-shell-escape title_page
```
