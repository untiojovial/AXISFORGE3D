## Build

```bash
python tools/research/phase7/make_tables.py --results research/phase7/results --out publication/intelligent_service_robotics/tables
python tools/research/phase7_extension/make_tables_x.py --out publication/intelligent_service_robotics/tables
python tools/research/phase7/make_figures.py --results research/phase7/results --out publication/intelligent_service_robotics/figures
cd publication/intelligent_service_robotics
pdflatex -no-shell-escape main && bibtex main && pdflatex -no-shell-escape main && pdflatex -no-shell-escape main
```
