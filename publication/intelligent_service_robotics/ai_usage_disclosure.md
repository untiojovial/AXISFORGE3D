# Disclosure of the use of generative AI tools

**Draft for the author to review, edit and sign.** It must match what actually happened. Check the
target journal's current AI policy before submission. The guidelines page could not be read without a
Springer login during preparation.

## Tools

- **Claude Code** (Anthropic): an agentic coding assistant, used through the claude.ai cloud environment.
- **ChatGPT** (OpenAI): used by the author. The author must describe the uses, which are not recorded
  in the repository.

## What Claude Code did (Phases IV–VII, recorded in the repository history)

**Code.** It wrote and modified research code:

- Rust planner instrumentation (stage timings, the `--static-quality` export);
- Python experiment tools under `tools/research/` and `research_grasping/`;
- tests.

**Runs.** It ran the experiments in a cloud container:

- planner runs;
- MuJoCo simulations;
- model training;
- statistical analyses.

The commands and seeds are in the result files and protocols.

**Writing.** It drafted:

- the protocols, the frozen hypotheses and the audit documents;
- this manuscript's text, tables and figures, generated from the stored results by scripts.

**Literature.** It searched for literature and checked each reference against a primary source
(`research/phase7/references_verified.json`). Unverifiable references were not used.

**What it did not do.**

- It did not decide the research questions on its own: they come from the author's instructions.
- It is not an author.
- It cannot take responsibility for the work.

## What the author is responsible for

- The scientific claims.
- Checking every result against the repository.
- The final wording.
- The choice to submit.

## Safeguards against AI-induced errors

- **Generated numbers.** Every number in the manuscript is a macro generated from result files
  (`tools/research/phase7/make_tables.py`). Figures are generated by `make_figures.py`, and nothing was
  edited by hand.
- **Frozen confirmation.** The confirmation protocol, models and analysis were frozen and signed by
  SHA-256 hashes before the test set was opened (`research/phase7/PHASE7_MODEL_FREEZE.json`).
- **Simulated reviews.** The four internal reviews in `research/phase7/scientific_review.md` were
  written by the same AI system. They are a self-check, **not** independent peer review.
