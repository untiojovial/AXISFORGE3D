\section{Second confirmation on new EGAD objects}\label{sec:newconf}

\paragraph{Design.} The second confirmation used positions 300--499 of the same seeded EGAD draw as the first: \nxObjects{} cells of the same object family that had never been built, planned or simulated (checked against every file and commit). Everything it depends on was committed and recorded with SHA-256 digests in Git before any of these objects was catalogued: the protocol, the selection result, the frozen models, the analysis code and a fixed compiled planner binary, whose digest every stage re-checked. This is a freeze in Git, not a registry preregistration. One deviation is declared: the mesh of one object (position 300) was scaled and decomposed, without planning or simulation, while the build script was being tested before the freeze. Preparation, catalogue and planning failures were recorded and not replaced; no reserve set exists.

\paragraph{Hypotheses.} Four primary hypotheses on the viable objects, with Holm correction and one-sided $\alpha=0.025$: C1, X (Joint-multi) examines fewer candidates than M0 (geometric-mean $N_F$ ratio, $t$ test on per-object log ratios); C2, X's robustness is non-inferior to M0's with a $-5$-point margin, tested with Tango's score test \cite{tango1998}, which replaces the test that the audit of the first confirmation found anti-conservative; C3, X's $N_F$ is non-inferior to M1's with the 1.25 ratio margin of the first confirmation; and C4, X's cold-process planning time is lower than M0's, measured with the integrated implementation (three fresh processes per object and method, one pinned thread, random method order). Secondary (Holm within the family): S1, load tolerance non-inferior to M0 ($-10$ points); S2 and S3, robustness at all three torsions superior to M1 and to M0 (exact McNemar). The Wilcoxon signed-rank test is reported for C1 and C4 as a rank-based sensitivity analysis; it tests a location shift, not the geometric mean, and does not decide support. Planned power, from resampling development and first-confirmation data, was high for C1 and C3 but between 0.21 and 0.997 for C2 and between 0.54 and 1.00 for C4, depending on whether the development effects transfer; the margins were not changed to gain power.

\paragraph{Objects.} Of the \nxObjects{} objects, \nxPrepFail{} failed preparation and \nxCatFail{} failed cataloguing; \nxViable{} had a viable candidate and \nxNoViable{} had none. There were \nxPlanErrors{} planning errors and \nxUnstable{} unstable simulation starts among \nxTrials{} trials. The native orders matched the Python replay of the frozen models (\nxReplayMzero{} and \nxReplayLearned{} mismatches).

\paragraph{Dependence between neighbouring cells.} EGAD cells are a grid of complexity and difficulty, and neighbouring cells can resemble each other.
