\section{Second confirmation on new EGAD objects}\label{sec:newconf}

\paragraph{Design.} The second confirmation used positions 300--499 of the same seeded EGAD draw as the first: \nxObjects{} cells of the same object family that had never been built, planned or simulated (checked against every file and commit). Everything it depends on was committed and recorded with SHA-256 digests in Git before any of these objects was catalogued: the protocol, the selection result, the frozen models, the analysis code and a fixed compiled planner binary, whose digest every stage re-checked. This is a freeze in Git, not a registry preregistration. One deviation is declared: the mesh of one object (position 300) was scaled and decomposed, without planning or simulation, while the build script was being tested before the freeze. Preparation, catalogue and planning failures were recorded and not replaced; no reserve set exists.

\paragraph{Hypotheses.} Four primary hypotheses on the viable objects, with Holm correction and one-sided $\alpha=0.025$: C1, X (Joint-multi) examines fewer candidates than M0 (geometric-mean $N_F$ ratio, $t$ test on per-object log ratios); C2, X's robustness is non-inferior to M0's with a $-5$-point margin, tested with Tango's score test \cite{tango1998}, which replaces the test that the audit of the first confirmation found anti-conservative; C3, X's $N_F$ is non-inferior to M1's with the 1.25 ratio margin of the first confirmation; and C4, X's cold-process planning time is lower than M0's, measured with the integrated implementation (three fresh processes per object and method, one pinned thread, random method order). Secondary (Holm within the family): S1, load tolerance non-inferior to M0 ($-10$ points); S2 and S3, robustness at all three torsions superior to M1 and to M0 (exact McNemar). The Wilcoxon signed-rank test is reported for C1 and C4 as a rank-based sensitivity analysis; it tests a location shift, not the geometric mean, and does not decide support. Planned power, from resampling development and first-confirmation data, was high for C1 and C3 but between 0.21 and 0.997 for C2 and between 0.54 and 1.00 for C4, depending on whether the development effects transfer; the margins were not changed to gain power.

\paragraph{Objects and execution.} All \nxObjects{} objects were prepared and catalogued: \nxViable{} had a viable candidate and \nxNoViable{} had none. There were \nxPlanErrors{} planning errors, \nxUnstable{} unstable simulation starts among \nxTrials{} trials, and \nxReplayMzero{} and \nxReplayLearned{} mismatches between the native orders and a Python replay of the frozen models. The container restarted once during preparation; the run resumed from per-object outputs and no object was re-sampled. Timing ran with every other job paused (load average about 1, the timing process itself).

\paragraph{Efficiency.} \textbf{C1} was supported: X examined \nxConeEff{} \nxConeCI{} times as many candidates as the original planner, fewer on \nxConeFewer{} objects and more on \nxConeMore, with \nxConeTies{} ties (both orders found a viable candidate first); the rank-based sensitivity agreed ($p=\nxConeWilcoxonP$). \textbf{C3} was supported: the $N_F$ ratio to M1 was \nxCthreeEff{} \nxCthreeCI, well inside the 1.25 margin. X and the first confirmation's Joint behaved almost identically ($N_F$ ratio \nxXJhNF, robustness difference \nxXJhRob{} points, load \nxXJhLoad).

\paragraph{Robustness.} \textbf{C2} was supported: X's robustness was \nxCtwoEff{} points higher than the original planner's (\nxRobX\% vs \nxRobMzero\%), Tango 95\% CI \nxCtwoCI{} and Newcombe \nxCtwoNewcombe, with \nxCtwoFav{} objects robust only with X and \nxCtwoUnfav{} only with M0. Non-inferiority does not depend on a single object here: in a post-hoc check, moving one more object to ``robust only with M0'' leaves the interval at \phCtwoOneMoreCI. The interval also excludes zero, but superiority was not a pre-specified hypothesis, and that reading is fragile: the same change brings the lower limit below zero. The robustness gain that selected X did not replicate: robustness at all three torsions was the same as M1's (S2, \nxStwoEff{} points \nxStwoCI) and close to M0's (S3, \nxSthreeEff{} \nxSthreeCI), against a development advantage of \vAdv{} points over M1. At torsion 0.001~m, X$-$M0 was \nxTorLow{} \nxTorLowCI. Load tolerance was non-inferior to the original planner's at the 10-point margin (S1, \nxSoneEff{} \nxSoneCI).

\paragraph{Time.} \textbf{C4} was not supported: the geometric-mean ratio of cold-process times was \nxCfourEff{} \nxCfourCI{} on all \nxObjects{} objects (median \nxTimeX~s vs \nxTimeMzero~s). X was slower on \nxCfourMore{} objects and faster on \nxCfourFewer, and the frozen one-sided Wilcoxon sensitivity pointed against X ($p\,\nxCfourWilcoxonP$). Described post hoc, the per-object median ratio was \phCfourMedian{} (two-sided Wilcoxon $p=\phCfourWilcoxonTwo$): the learned stage adds a few milliseconds to every object, and the shorter search repays it only on some. The interval excludes time differences larger than about 2\%, but no equivalence margin was pre-specified, so this is no test of equal cost.

\paragraph{GPD, fallback and dependence.} GPD+gate (ranking-controlled, Sect.~\ref{sec:cost}) needed \nxGPDNF{} \nxGPDNFCI{} times the original planner's candidates; its first grasps were as robust (\nxGPDRob{} points \nxGPDRobCI) and less load tolerant (\nxGPDLoad{} \nxGPDLoadCI). The round-robin hybrid had \nxFbViol{} violations of its bound and geometric-mean $N_F$ \nxHybridNF. EGAD cells form a grid of complexity and difficulty, and neighbouring cells can resemble each other; bootstrapping by difficulty letter (\nxClusters{} clusters) gave \nxClusterCone{} for C1, \nxClusterCtwo{} points for C2, \nxClusterCthree{} for C3 and \nxClusterCfour{} for C4, consistent with the primary analysis.
