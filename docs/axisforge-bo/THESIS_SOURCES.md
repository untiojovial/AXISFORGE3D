## Visual inference and thesis implications

Thesis §2.4 pp.11–12 describes frozen pretrained inference and mentions DINOv2; §5.2.1 p.37 states a 384-dimensional visual embedding. Official DINO and DINOv2 source each define a `vit_small` with embedding dimension 384. DINO's `VisionTransformer.forward` returns the normalized first/class token; DINOv2 `forward_features` exposes `x_norm_clstoken` and `forward` applies its head to that token. These facts show that a 384-vector is compatible with multiple small models; they do **not** identify which model, patch size, checkpoint, image normalization, token pooling or model version the thesis used. The DINOv2 `forward` head and any changed checkpoint/configuration must be checked for the intended inference path. No visual model weights or visual inference were run in this project. For reproducibility, obtain the original code, checkpoint digest, eight-view aggregation and preprocessing.

The thesis §2.7.2–3 describes “Approximate Deep Feature Kernels” and “Independent Feature Transformations,” but Fig. 2.5 cites [26], whose actual expansion is **Adaptive Deep Kernel Fitting with Implicit Function Theorem**. [26] §3.4 specifies task-adapted GP base parameters and meta-learned feature parameters; the thesis concepts are not interchangeable with that algorithm. Full detail and caveats appear in `META_RESEARCH.md`.

The current GPJax example implements a custom kernel `k(φ(x), φ(x'))` via an Equinox neural network and a base kernel, fits a GP by conjugate marginal likelihood with Optax, and chooses Matérn-5/2 in code. Its surrounding prose calls the base kernel third-order Matérn; treat executable code and prose separately. It is not evidence that the thesis used this exact version, nor that the example implements implicit bilevel meta-learning or multimodal features.
