## Implementation audit 1

**AUD-003 — P1, ASSIGNED (BO):** finite inputs can produce silent non-finite results: `expected_improvement([-1e308], [1], 1e308)` returned `[inf]`; `StationaryKernel(kind='matern52')([[-1e308]], [[1e308]])` produces NaN due to overflow and `inf*0`. This violates the numerical stability and explicit-failure gate. Correct by stable computation or validated explicit failure, test extremes across kernel/acquisition functions, and independently re-audit after tests. A passing ordinary-value test does not close the issue.

Scoped context-memory review found strict `<` timestamp filtering, group exclusions, and copied immutable records consistent with the stated design; provenance of caller-provided values/times cannot be verified by the component. Full gate remains pending executable adversarial and integration evidence.

**AUD-004 — P1, ASSIGNED (integration):** `BayesianOptimizer.best()` uses a shallow dict copy; editing the returned `x` or `context` list mutates internal observations, silently corrupting later model fits and checkpoints. Return independent deep/immutable data; test attempted mutations and re-fit/checkpoint behavior. `ask` failure after sampling also advances RNG; transactional behavior or explicit policy and regression required.

**AUD-005 — P1, ASSIGNED (meta):** proposed PyTorch DKL does not handle GPU coherently: `predict` creates CPU tensors and converts results directly to NumPy, and `_tensor` does not follow model device. Support and test device-consistent behavior or explicitly reject unsupported GPU. Failed fitting can modify existing parameters before failure; restore prior state or invalidate it explicitly. Verify numerical failures and posterior independently. GPU was not available for an actual test at this audit; finding is from direct source inspection.
