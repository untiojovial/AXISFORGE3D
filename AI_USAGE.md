# Use of AI systems in AxisForge3D

This file records how generative AI systems were used to build the software, run the experiments and write the
manuscript. It follows the target journal's policy as relayed to the author:

- language models cannot be authors;
- substantive use must be documented in the Methods section and in the declarations;
- the human author is responsible for the content.

The human author:

### Claude Code (Anthropic)

Claude Code is an agentic coding assistant, run in the claude.ai cloud environment under the author's instructions.
It authored the commits named `Claude <noreply@anthropic.com>`, each with a session trailer: 86 from 2026-11-12 to commit `31550aa` (2026-11-26), and the later documentation commits. Its
use was **substantial**, as assistance under the author's supervision:

- **Programming and technical implementation.** The Rust engine (native learned ordering, model export, timing
  instrumentation, CLI options), the Python research tools and the tests.
- **Experiments and simulations.** It ran every Phase V–VII and extension experiment in a cloud container:
  - planning and catalogues;
  - MuJoCo simulations;
  - model training;
  - the GPD build and scoring;
  - timing;
  - both confirmations.
- **Statistical analysis.** Statistics, audits, power analyses, the corrections register.
- **Documentation and scientific writing.**
  - Protocols, registers, licence notices and documentation.
  - Drafts of the manuscript and the supplement.
  - The literature search and its verification against primary records (Crossref, arXiv, publisher and repository
    pages).
  - Tables and figures, generated by script from result files.

It did not make the final scientific decisions, and it is not an author.

## Relation to the author's master's thesis

The study is independent research carried out after the author's master's thesis:

> E. Pérez González, *Robot grasping with Bayesian optimization informed with foundational models*, Master's thesis,
> Universidad de Zaragoza, 2025, TAZ-TFM-2025-047, https://zaguan.unizar.es/record/152263 (read on 2026-11-27).

| | Thesis (2025) | This article |
|---|---|---|
| Problem | Sequential Bayesian optimisation of grasps for a humanoid hand in simulation (Simox) | The examination order of a complete parallel-jaw planner |
| Vision features | DINO features informing the optimisation, with context | Frozen DINOv2, DINOv3 and OpenCLIP features tested as one representation among others; negative result |
| Deep kernels | Deep-kernel Gaussian processes (DKL, ADKF-IFT) | Studied through an ordering-ceiling analysis, not run |

**Reuse.** No text, figure or result of the thesis is reused; a shingle comparison of the sources found no shared
7-word sequence. The repository's AxisForgeBO modules reconstruct parts of the thesis method for other uses, and the
thesis PDF is not redistributed.

**Supervisor.** The thesis supervisor, Rubén Martínez Cantín, did not take part directly in this study (author's
statement). He is not a co-author, and the article has no acknowledgements section, by the author's decision.

## Safeguards

- **No hand-typed numbers.** Every number in the manuscript is a macro generated from committed result files. The
  figures are generated by plotting scripts; no generative image model was used.
- **Freeze before evaluation.** The confirmatory protocols, models, analysis code and planner binary were frozen in
  Git with SHA-256 digests before the test objects were catalogued or planned. This applies to Phase VII and to the
  extension (`PHASE7X_FREEZE.json`). These are digests, not signatures, and not a registry preregistration.
- **Kinds of review.**
  - The internal audits were written by AI systems: Claude Code, and ChatGPT through the author's instructions. They
    are self-checks.
  - The author's review of 26 November 2026 is a human review by the author, recorded in `HUMAN_REVIEW_RECORD.md`.
  - Neither is independent peer review. `research/phase7_extension/EXTERNAL_REVIEW_PACKAGE.md` is prepared for an
    independent audit.
- **Negative results kept.** No experiment, negative result or historical result was removed. Corrections are logged
  in `research/phase7_extension/FINAL_CORRECTIONS_REGISTER.md`.
- **Later work needs approval.** Results and text produced after the author's review need the author's approval
  before submission, for example the Optuna exploratory analysis and the final literature review.
