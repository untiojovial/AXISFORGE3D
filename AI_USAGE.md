# Use of AI systems in AxisForge3D

This file records how generative AI systems were used to build the software, run the experiments and write
the manuscript. It follows the target journal's policy as relayed to the author:

- language models cannot be authors;
- substantive use must be documented, in the Methods section and in the declarations;
- the human author is responsible for the content.

Entries that only the author can confirm are marked **[author]**.

## Systems and roles

### Claude Code (Anthropic)

Claude Code is an agentic coding assistant, run in the claude.ai cloud environment. It authored 75 commits,
named `Claude <noreply@anthropic.com>` (2026-11-12 to 2026-11-26), each with a session trailer. Its use was
**substantial**:

- **Implementation.** The Rust engine (native learned ordering, model export, timing instrumentation, CLI
  options), the Python research tools and the tests.
- **Experiments.** Every Phase V–VII and extension experiment, run in a cloud container: planning,
  catalogues, MuJoCo simulations, model training, the GPD build and scoring, timing, and both
  confirmations.
- **Analysis.** Statistics, audits, power analyses, the corrections register.
- **Writing.** Protocols, registers, licence notices, documentation, the manuscript and the supplement.
  Tables and figures are generated by script from result files.
- **Checks.** References checked against primary sources where they were reachable.

## Relation to the author's master's thesis

The study continues the author's master's thesis:

> E. Pérez González, *Robot grasping with Bayesian optimization informed with foundational models*,
> Universidad de Zaragoza, 2025 (TAZ-TFM-2025-047; identifier from the author-supplied PDF).

**What the thesis did.** It used DINO features in a deep-kernel Gaussian process for sequential Bayesian
optimisation of grasps.

**How this article differs.** It learns a fixed examination order for a complete planner, which is not
sequential Bayesian optimisation. It tests frozen foundation-model features as one representation among
others, with a negative result.

**What was kept.** The repository's AxisForgeBO modules reconstruct parts of the thesis method for other uses.
The thesis PDF is not redistributed.

## Safeguards

- **No hand-typed numbers.** Every number in the manuscript is a macro generated from committed result files,
  and the figures are generated by scripts.
- **Freeze before evaluation.** Confirmatory protocols, models, analysis code and the planner binary were
  frozen in Git with SHA-256 digests before the test objects were catalogued or planned. This applies to
  Phase VII and to the extension (`PHASE7X_FREEZE.json`). These are digests, not signatures and not a
  registry preregistration.
- **Reviews are not independent.** The internal reviews and the adversarial audits were written by AI systems:
  Claude Code, and ChatGPT through the author's instructions. They are self-checks, not independent peer
  review. `research/phase7_extension/EXTERNAL_REVIEW_PACKAGE.md` is prepared for an independent audit, which
  would not replace the author's approval either.
- **Negative results kept.** No experiment, negative result or historical result was removed. Corrections are
  logged in `research/phase7_extension/FINAL_CORRECTIONS_REGISTER.md`.
